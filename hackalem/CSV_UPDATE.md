# Подключение найденного CSV

Это обновление проекта шагов 4–5. Все данные берутся из приложенного пользователем
`hackathon dataset anonymized.csv`. Его содержимое скопировано без изменений.
Старый `hackathon-dataset-demo.jsonl` больше не читается, и его 12 записей не добавляются.

## Установка

1. Остановить сервер сочетанием Ctrl+C и сохранить локальную копию проекта.
2. Скопировать содержимое архива в папку hackalem с заменой app.py, recommender.py
   и файлов static. Объединить папки data и tests с существующими папками.
3. Из терминала в корне проекта выполнить:

```powershell
.\.venv\Scripts\python.exe recommender.py
.\.venv\Scripts\python.exe -m uvicorn app:app --reload --host 127.0.0.1
```

Открыть `http://127.0.0.1:8000` и обновить страницу Ctrl+F5.
Новые зависимости не нужны: используются прежние FastAPI/Uvicorn и стандартная библиотека Python.

## Что изменено

- CSV читается через csv.DictReader, а не как JSONL.
- categories, event_formats, languages, busy_dates разделяются по символу `|`.
- Цена преобразуется в int; пустой max_hours — в None, заполненный — в число.
- True/False преобразуются в настоящие логические значения, не через bool(строка).
- Пропущенные поля, дубли id, неверные числа, флаги и даты дают ошибку загрузки.
- Поля synthetic, city_imputed и price_imputed сохранены; их отметки видны в карточках.
- Статистика /options и /contractors вычисляется при чтении файла.
- Фильтры и правило сортировки прежние: цена по возрастанию, затем id. AI пока нет.
- При любом результате показываются причины исключений. Их количества могут пересекаться.
- Списки формы, уведомления о происхождении данных и кнопки примеров обновлены.
- /health проверяет доступность API, но не загрузку CSV; для данных используются /options и /contractors.

## Контрольные значения на приложенном файле

66 профилей, 13 с synthetic=True; 8 с city_imputed=True, 18 с price_imputed=True.
53 профиля без признака synthetic не объявляются проверенными или доступными для бронирования.
9 профилей имеют max_hours=None. Все 66 id уникальны.

Подходят 4 записи; показаны HK-68220, HK-53108, HK-91112.
На 2026-11-14: HK-68220, HK-76268, HK-91112.
Редкая категория Флорист на базовых условиях: HK-39372, HK-90001.
Бюджет 100000: no_match. Астана + Декоратор: no_category.

## Локальные проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_csv_update.py" -v
```

Тесты проверяют именно этот приложенный каталог. При замене каталога контрольные числа меняются.
API можно проверить через /docs. Это функциональные проверки локального проекта, не нагрузочный тест.

## Хранение данных

Не публиковать CSV и секреты; использовать данные в пределах разрешения организаторов.
Добавить в существующий корневой .gitignore (не заменять его целиком):

```gitignore
.venv/
__pycache__/
.env
.env.*
data/*.csv
data/*.jsonl
```

.gitignore не удаляет файлы из истории, если они уже были добавлены в Git.
Срок хранения и удаление локальных копий — по инструкции организаторов.
